## GitHub concepts
- Repository: Stores the files and their change history.
- Issue: Describes planned work and the criteria for completing it.
- Branch: Allows changes to be developed separately from the default branch.
- Commit: Records a set of changes with a message explaining them.
- Pull request: Proposes merging changes from one branch into another and provides a place to review them.
- Default branch: Holds the main version of the repository.

## How the workflow connects
The issue defines the goal, tasks, and acceptance criteria.
I make the documentation changes on feature/github-ai-workflow.
Separate commits record meaningful stages of the work.
The pull request brings those changes together for review.
After addressing feedback, I merge the pull request into the default branch.
